# Face detector data

`haarcascade_frontalface_default.xml` is the OpenCV frontal-face detector used by the optional face attendance module. It is included because some OpenCV Python wheels do not ship the `cv2/data` XML files.

The detector XML retains its original Intel license and copyright notice in its header. It is sourced from the [OpenCV 4.x cascade collection](https://github.com/opencv/opencv/tree/4.x/data/haarcascades).
